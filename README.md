# Sumon Power — lightweight proxy demo

This repository contains a small Flask-based proxy demo that injects a fingerprint-spoofing JavaScript into proxied HTML pages per-profile.

How to run (Replit recommended):
1. Open this repository on Replit: https://replit.com/github/Sumon1141/sumon-power
2. Click the "Import from GitHub" or "Run" button on Replit.
3. When running, open the displayed web URL. Enter a target site (e.g., example.com) and choose a profile.

Notes:
- This is a demo for educational purposes. Some sites with strict Content-Security-Policy (CSP) may block the injected script.
- Do not use this project for illegal activities.
